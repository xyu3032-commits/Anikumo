# Anikumo助手 Discord 机器人隐私政策

最后更新：2026-11-12

「Anikumo助手」（下称「本机器人」）是 Anikumo 官方 Discord 服务器的专用辅助机器人。本政策说明本机器人在运行过程中对信息的处理方式。

## 1. 我们处理的信息

本机器人的功能仅限于服务器配置管理（身份组与入群引导设置）。在配置过程中，本机器人通过 Discord 官方 API 接触到的信息仅限于：

- 服务器的基本结构信息（服务器、频道、身份组的名称与 ID）；
- 由 Discord 平台托管的入群引导设置（问题、选项及其对应的身份组）。

## 2. 我们不做的事

- **不读取、不存储成员的消息内容**；
- **不收集成员的个人资料**（包括账号密码、邮箱、支付信息等）；
- **不追踪成员行为**，不进行广告、画像或数据分析；
- **不向任何第三方出售、共享或转让数据**；
- 不在 Discord 之外建立任何成员数据库。

成员选择入群引导选项后，身份组的授予由 Discord 平台自身的机制完成；相关记录保存在 Discord 平台内，受 Discord 官方隐私政策约束。

## 3. 数据留存

本机器人不在 Discord 之外长期保存任何服务器或成员数据。配置操作完成后，本机器人不保留操作过程中接触到的信息副本。

## 4. 数据安全

本机器人的访问凭据由服务器所有者保管，仅用于本政策所述的配置用途。任何人都不会通过本机器人获取其他成员的私人信息。

## 5. 政策变更与联系方式

本政策可能随功能变化而更新，更新版本将发布于本页面所在的仓库中。如对本政策有疑问，请在本仓库提交 Issue：
https://github.com/xyu3032-commits/Anikumo/issues

# Privacy Policy — Anikumo Assistant Discord Bot

Last updated: 2026-11-12

"Anikumo Assistant" (the "Bot") is a private helper bot for the official Anikumo Discord server. The Bot's functions are limited to server configuration (roles and member onboarding settings) via Discord's official API. The Bot does **not** read or store message content, does not collect members' personal data, does not track member behavior, and does not sell or share any data with third parties. Role assignment through onboarding is performed by Discord's own systems, and related records remain within Discord under Discord's Privacy Policy. The Bot retains no copies of server or member data outside Discord after configuration is complete. Questions: please open an issue in this repository.
