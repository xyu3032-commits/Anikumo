# Anikumo助手 Discord 机器人服务条款

最后更新：2026-11-12

「Anikumo助手」（下称「本机器人」）是 Anikumo 官方 Discord 服务器的专用辅助机器人，由服务器所有者运营。您在本服务器内与本机器人相关的互动，即表示您同意以下条款。

## 1. 用途

本机器人仅用于本服务器的管理与配置辅助，包括：

- 创建和管理身份组（角色）；
- 配置新人入群引导（成员回答引导问题后，由 Discord 官方机制自动授予对应身份组）。

本机器人不提供面向公众的通用服务，不会在本服务器之外的任何服务器运行。

## 2. 使用规范

- 成员通过 Discord 官方的入群引导界面选择身份组，该过程由 Discord 平台本身完成；
- 禁止尝试干扰、滥用或绕过本机器人及服务器的正常配置机制；
- 本机器人的权限仅限于服务器所有者授予的管理范围，所有者可随时调整或移除本机器人。

## 3. 服务现状与责任

- 本机器人按「现状」提供，不对持续可用性作任何保证；
- 本机器人不发送营销信息、不提供付费功能；
- 因 Discord 平台自身的变更、中断或政策调整导致的功能不可用，不属于本机器人的责任范围。

## 4. 条款变更

本条款可能随功能变化而更新，更新后的版本将发布于本页面所在的仓库中，恕不另行单独通知。

## 5. 联系方式

如对本条款有疑问，请在本仓库提交 Issue：

The Bot offers no paid features and runs in no server other than the official Anikumo server. Questions: please open an issue in this repository.
