# Anikumo 用户手册

版本：v1.0.0 ｜ 包名：com.anikumo.app ｜ 平台：Android（主）/ Windows / macOS / Linux / iOS

Anikumo 是一款开源三合一应用：动漫、漫画、小说装在一个 App 里。无广告、无内置片库，数据保存在你自己的设备上。

## 一、安装与首次启动

1. 从项目发布页获取与你设备对应的安装包（Android 优先选 arm64 版）。
2. Android 安装时如系统提示「未知应用」，在系统设置中允许本次安装后继续。
3. 首次启动会显示免责说明，请完整阅读并同意后再使用；不同意则请勿使用（详见《免责手册》）。
4. 桌面端（Windows / macOS / Linux）解压或安装后直接启动，界面与操作与移动端基本一致，另支持键盘快捷键。

## 二、界面总览

顶部刊头为「Anikumo ANIME」，频道栏共 7 个频道：

| 频道 | 用途 |
|---|---|
| 推荐 | 热门番组、今日主视觉、本日榜单 |
| 精选 | 编辑精选、趋势热播 |
| 发现 | 内容发现、漫画专区与小说专区入口、按标签发现 |
| 时光 | 继续观看、观看历史、我的收藏夹 |
| 时间表 | 按星期查看每周放送安排 |
| 追番 | 收藏分组与追番进度 |
| 我的 | 个人档案、内容与偏好、数据与应用、设置 |

底部为悬浮胶囊导航。工具箱已并入设置：**我的 → 设置 → 工具箱**。

## 三、动漫

- **找番**：推荐页看榜单与主视觉；时间表按星期查放送；发现页可用排行榜、今日上新、每日推荐、相似推荐、即将开播等方式找番；也可直接点顶部搜索，一次搜索同时查动漫、漫画、小说（见第六节）。
- **详情页**：简介、评分、话数、角色与声优、制作人员、关联条目与评论（数据来自 Bangumi）。
- **播放**：点集数即可播放，播放器支持弹幕（可在弹幕设置中按关键词屏蔽、调整显示）、Anime4K 实时超分（在播放设置中开启）、硬件解码与渲染器切换、外部播放器、后台播放、截图导出，并支持 Syncplay 与朋友异地一起看。
- **追番**：在详情页收藏并分组（在看 / 想看 / 看过等）；登录 Bangumi 账号后可同步收藏。
- **离线**：整话下载后断网可看，下载目录与并发数在「设置 → 工具箱 → 下载设置」中调整。
- **续看**：看过的番会出现在「时光 → 继续观看」，点开从上次进度继续。

## 四、漫画

- **浏览**：从「发现 → 漫画专区」进入，按分类横排浏览（恋爱、热血等分类）、查看今日精选。
- **阅读器**：支持条漫与分页两种模式，横屏自动双页；相邻章节自动预加载，翻页不等待；阅读进度自动记忆，下次打开回到上次位置。
- **连看不卡**：阅读器有专用图片缓存，连看几十话也不会反复重新下载图片。
- **收藏与下载**：收藏后有新话会显示「+N 话」徽标；可逐话下载，断网阅读。

## 五、小说

- **阅读**：点开书籍进入目录，选章节开始阅读，正文排版可调（字体、字号、主题在阅读设置中调整）。
- **进度**：阅读进度自动记忆，换设备前可通过备份或 WebDAV 同步（见第七节）。
- **下载**：章节可下载后离线阅读。

## 六、跨区搜索与命令面板

- **统一搜索**：顶部搜索框上方有四段切换——全部 / 动漫 / 漫画 / 小说。「全部」模式一次看齐三区结果。
- **命令面板**：在「设置 → 工具箱 → 命令面板」输入关键词，可直达任意功能，不用逐层找菜单。

## 七、数据：备份与同步

- **本地备份与恢复**：设置 → 工具箱 → 本地备份与恢复。历史、收藏、榜单可导出为一个文件；换机或重装前先导出，新装后在同一入口导入恢复。
- **WebDAV 同步**：在「我的 → 同步备份」中填入你自己的 WebDAV 服务器后，观看历史、收藏、弹幕屏蔽设置可跨设备同步。数据只存放在你自己的服务器上。
- 注意：漫画的收藏、进度与已下载章节不在本地备份范围内，请留意单独保管。

## 八、个性化与设置

在「我的 → 内容与偏好」中可以调整：

- 外观：五种番剧卡片样式、玻璃效果强度、主题色与动态取色、定时深色模式、默认启动页、字体
- 播放：解码与渲染、超分、后台播放等
- 弹幕：开关、屏蔽关键词、显示区域与透明度等
- 轻量与安全：低内存 / 流畅模式（老设备更顺滑）、PIN 应用锁、代理设置
- 存储管理：查看与清理图片缓存和下载内容

## 九、使用提示

- 滑动卡顿时，先到设置里开启流畅模式，并清理一次图片缓存。
- 每周放送的时间与部数随当季安排变化，以时间表页实际显示为准。
- 更多问题见《常见问题》。
