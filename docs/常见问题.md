# Anikumo 常见问题

版本：v1.0.0 ｜ 包名：com.anikumo.app

## 安装与更新

**Q：Android 应该装哪个包？**
A：按设备架构选：绝大多数近年手机选 arm64 版；老设备选 v7a 版；模拟器选 x86_64 版。不确定时先装 arm64 版。

**Q：安装时提示无法安装 / 与已装版本冲突怎么办？**
A：先确认包名同为 com.anikumo.app 且签名一致即可直接覆盖安装。如提示冲突，先在旧版「设置 → 工具箱 → 本地备份与恢复」导出备份，再卸载旧版安装新版，最后导入备份恢复数据。

**Q：这款软件收费吗？**
A：完全免费、开源、无广告。如果有人向你收费提供本软件，你可向其索取赔偿（见《免责手册》）。

## 播放与阅读

**Q：播放卡顿怎么办？**
A：依次尝试：① 设置中开启流畅模式；② 播放设置里切换硬件解码或更换渲染器；③ 关闭 Anime4K 超分；④ 清理一次图片缓存后重试。

**Q：弹幕不显示？**
A：检查弹幕开关是否开启、当前作品是否有弹幕、屏蔽关键词是否误伤；在弹幕设置中调整显示区域与透明度后再试。

**Q：看漫画越看越卡？**
A：到设置 → 存储管理清理图片缓存；阅读器有专用缓存，连看几十话属于正常负载，清理后会重新建立缓存。

**Q：小说或漫画的阅读进度会丢吗？**
A：进度自动保存在本地；重装前请先做本地备份或开启 WebDAV 同步。注意漫画的收藏、进度与已下载章节不在本地备份范围内。

## 数据与同步

**Q：换手机怎么搬数据？**
A：旧机「设置 → 工具箱 → 本地备份与恢复」导出文件 → 文件传到新机 → 新机同一入口导入。或两台设备都配置同一个 WebDAV 后同步。

**Q：WebDAV 同步安全吗？数据会上传到官方服务器吗？**
A：不会。WebDAV 只连接你自己填写的服务器，数据存在你自己的服务器上；官方不收集任何个人信息（见《隐私手册》）。

**Q：工具箱去哪了？**
A：新版工具箱已并入设置：我的 → 设置 → 工具箱，命令面板、卡片样式、玻璃效果、本地备份与恢复、下载设置都在里面。

## 其他

**Q：为什么有的番在时间表里找不到？**
A：时间表按当季每周放送编排，未定档或不在本周放送的作品不会出现，可用搜索直接查找。

**Q：发现界面与手册不一致 / 功能有问题，怎么反馈？**
A：记录你的设备型号、系统版本、App 版本（v1.0.0）和操作步骤，在项目发布渠道提交反馈。
